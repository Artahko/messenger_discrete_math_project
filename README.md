# Реалізовані алгоритми

У проєкті реалізовано такі алгоритми: RSA, Rabin, DSA, ElGamal, ECC, AES

AES був доданий окремо як сучасний стандарт симетричного шифрування, який активно використовується у реальних продуктах.

---

# Аналіз алгоритмів

## RSA

RSA демонструє високий рівень безпеки, проте потребує значно більше пам’яті та ресурсів для шифрування і дешифрування повідомлень. Саме тому в сучасних системах його дедалі частіше замінюють на ECC.

## Rabin та ElGamal

Хоча ці алгоритми показують хороші результати з точки зору криптографічної стійкості, на практиці вони використовуються значно рідше.

## ECC

ECC забезпечує такий самий рівень безпеки, як і класичні алгоритми, але використовує ключі значно меншого розміру, що забезпечує ефективніше використання пам’яті та високу продуктивність.

Єдиним недоліком ECC, як і інших криптографічних систем, є потенційна вразливість до side-channel attacks.

### Де використовується ECC

ECC активно застосовується у:

* захисті інтернет-з’єднань;
* сучасних месенджерах (Telegram, WhatsApp);
* криптовалютах (Bitcoin);
* смартфонах та смарт-пристроях.

# Криптографічна схема

## Генерація ключів

Кожен користувач при вході в систему генерує ECC-пару ключів на кривій `secp256k1`.

* Публічний ключ завантажується на сервер.
* Приватний ключ ніколи не покидає браузер користувача.

## Обмін ключами

Перед відправкою повідомлення:

1. Клієнт отримує публічний ключ співрозмовника.
2. Обчислюється спільний секрет через ECDH (Elliptic Curve Diffie-Hellman).
3. Обидві сторони незалежно отримують однаковий секретний ключ.

## Шифрування повідомлень

Отриманий спільний секрет використовується як ключ AES‑256 для шифрування повідомлень.

Сервер отримує та зберігає лише зашифрований текст і не має можливості прочитати повідомлення користувачів.

# Висновки

У результаті виконання проєкту було реалізовано 6 алгоритмів шифрування, дешифрування та перевірки електронних підписів:

* RSA
* Rabin
* DSA
* ElGamal
* ECC
* AES

Проведений аналіз показав, що сучасними стандартами криптографії є:

* **ECC** — для генерації спільних секретів та електронних підписів;
* **AES** — для швидкого та безпечного шифрування повідомлень.

Саме тому в реалізації месенджера використовується:

* ECC — для створення спільного секрету між користувачами;
* AES — для шифрування повідомлень.
